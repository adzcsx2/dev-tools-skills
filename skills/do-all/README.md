# do-all

按严格阶段门禁，从头到尾执行一份已有实施或执行计划；目标计划仍在生成时会持续等待，准备完成后自动开始。

---

## 功能

- 从参数、当前对话或工作区中解析唯一最可能的执行计划
- 在目标计划尚未生成完成时持续监控，不执行半成品计划
- 严格按计划阶段顺序推进，每次只执行一个阶段
- 每个阶段必须通过相关测试、构建、lint、类型检查或确定性校验
- 阶段失败时持续诊断修复，不跳过失败或未验证的门禁
- 全部阶段完成后运行完整项目验证并逐项审计验收条件
- 保留用户已有改动，不执行未经授权的 commit、push、deploy 或 destructive action

## 用法

Claude Code：

```text
/do-all
/do-all docs/plan/example/00-执行文档.md
/do-all 按照即将生成的 00-执行文档.md 执行
```

Codex：

```text
$do-all
$do-all docs/plan/example/00-执行文档.md
```

没有参数且当前上下文只有一个明确计划时，命令会直接推断目标并开始执行；存在多个同等合理目标或完全没有可信计划时才会询问。

## 执行门禁

每个阶段至少覆盖与变更相关的：

- 单元、组件和集成测试
- 邻近行为回归测试
- build、typecheck、lint、format 或 schema 校验
- 关键 UI 流程的 E2E 或视觉验证
- 项目支持时的覆盖率检查

任何阶段失败或未验证时都不会进入下一阶段。完成全部阶段后还会运行完整相关测试套件并审查最终 diff。
